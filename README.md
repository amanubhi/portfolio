# Amanjot Ubhi — Data Analyst portfolio

Live: https://amanubhi.github.io/portfolio/

A responsive, buildless portfolio using HTML, CSS, and JavaScript. GitHub Pages publishes the root of `main`. No API keys, backend, or install step are required. Local preview: `python3 -m http.server 8766`.

## Content

Data Analyst is the primary positioning, with data and analytics engineering as supporting interests. Public case studies link to the Heat Check, Excel Salary Dashboard, and Edgebook repositories. Project previews are copied from their public repository screenshots. Heat Check is labeled synthetic; Edgebook demo data is fictional; the Excel project credits Luke Barousse's course and states salary coverage limitations.

Background and degree are based on the résumé supplied by the owner. The LinkedIn URL is verified against the résumé and GitHub profile; LinkedIn content could not be independently retrieved. Private and in-progress résumé projects, phone number, unsupported performance claims, and the full résumé are excluded.

## Interactive feature

Data Detective is a three-case fictional challenge about duplicates, missing salary data, and profit versus revenue. It includes correct/incorrect feedback, score, replay, keyboard-operable buttons, focus management, and status announcements. No visitor data is collected or sent to a server. Google Fonts supplies fonts; system fallbacks remain available.

## Editing

- `index.html`: public content, project links, SEO metadata.
- `style.css`: layout, responsive styles, reduced-motion support.
- `script.js`: game questions and scoring.
- `assets/`: local dashboard previews and favicon.

Historical demo directories are retained; the root homepage replaces the prior portfolio.
