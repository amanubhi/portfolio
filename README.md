# Aman Ubhi — Portfolio

Personal portfolio for Data Analyst and Business Analyst opportunities, with an engineering perspective on reproducible analysis.

**Live:** https://amanubhi.github.io/portfolio/

## Design & interactions

- Warm cream, burgundy, and orange identity; Bricolage Grotesque and DM Sans typography.
- Six projects with category filters, contextual metrics, source links, and expandable limitations.
- Interactive four-step analysis walkthrough grounded in the SQL dataset audit.
- Three fictional Data Detective cases with feedback, scoring, and replay.
- Responsive layouts, keyboard controls, visible focus, live status announcements, and reduced-motion support.
- Native HTML, CSS, and JavaScript; no build step, tracking, or backend.

## Preview

From this directory:

```sh
python3 -m http.server 8765
```

Open http://localhost:8765/. Check JavaScript syntax with `node --check script.js`.

GitHub Pages publishes the repository root on `main`. The legacy subdirectories are retained; the root files power the portfolio.

## Evidence and ownership

Project summaries distinguish public-data analysis, course-guided projects, synthetic business data, simulated experiments, and architecture work. dbt and AI agents are identified as developing skills. Project repositories contain source-specific methods and limitations.

Images in `assets/` are the existing portrait and project previews. Google Fonts are loaded externally with system font fallbacks. The résumé remains available as an existing downloadable asset.
